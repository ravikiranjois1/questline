# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), v2.1.

In short: be respectful, assume good faith, and keep disagreements about ideas, not people.
Harassment, personal attacks, and discriminatory language are not tolerated.

Report unacceptable behavior by opening a confidential issue or contacting the maintainers
directly. Reports will be reviewed and handled with discretion.
